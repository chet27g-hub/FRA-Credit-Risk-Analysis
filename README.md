# FRA Credit Risk Intelligence — Compact Peer Benchmarking

Open `index.html` in Chrome, or upload the contents to GitHub and enable GitHub Pages.

The Peer Benchmarking section is designed as compact FY2025 scorecard tables for:
- ICICI Bank vs HDFC Bank, Axis Bank and Kotak Mahindra Bank
- Bajaj Finance vs Cholamandalam, Shriram Finance and Mahindra Finance

It contains only two graphs: five-year gross NPA / gross Stage 3 trends for the bank peer set and NBFC peer set. The dashboard uses a light pastel theme throughout.

Data notes:
- The selected entities' core dashboard retains its FY2017–FY2026 working series.
- Peer scorecards show FY2025; charts show FY2021–FY2025.
- GNPA and Ind AS Stage 3 are not identical.
- PCR and credit-cost definitions/denominators vary by company.
- Missing observations are left blank, not set to zero.
- Verify all peer observations and definitions against original annual-report disclosures before final academic submission.
